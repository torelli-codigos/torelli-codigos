🚀 About Me

I'm a Full Stack Developer with 4+ years of professional experience, specializing in backend development and building scalable web applications using Laravel, React, and Next.js.

Since July 2022, I've been working on production-ready applications, contributing throughout the entire software development lifecycle — from requirements gathering and technical planning to implementation, deployment, and continuous improvement.

Throughout my career, I've contributed to 8+ collaborative projects across different domains and levels of complexity, gaining experience in designing and developing reliable solutions that address real business needs.

My main focus is backend engineering, particularly:

Backend Architecture: API development, business logic, MVC, Service Layer, and system design.
Database Management: PostgreSQL, multiple database environments, data modeling, and production data migrations.
Integrations: Payment gateways (Stripe and PIX), webhooks, and third-party services.
Complex Systems: Multi-currency applications, transactional workflows, and scalable business solutions.
Frontend Development: Building responsive and maintainable interfaces with React, Next.js, and TypeScript.
Software Quality: Automated testing, clean code, maintainability, and continuous improvement.

Beyond writing code, I actively participate in feature planning, requirements definition, and project organization alongside Product Owners. I also frequently act as a technical reference within development teams, helping other developers and contributing to architectural and technical decisions.

I'm passionate about building well-structured software, solving complex problems, and continuously evolving as an engineer.

Currently open to new opportunities and meaningful connections in software development.
